# Deck & Collect — support and privacy pages

The public support page and privacy policy for the Deck & Collect app
(iPhone, iPad and Mac), served with GitHub Pages:

- https://kdrtt.github.io/deckandcollect/support
- https://kdrtt.github.io/deckandcollect/privacy

The app links to both. If the app changes what it stores or downloads,
the privacy page changes in the same release.
